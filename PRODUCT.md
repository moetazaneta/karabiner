# Product

## Register

product

## Users

People who use or maintain this Karabiner configuration and need to quickly recall, search, and understand its keyboard shortcuts.

## Product Purpose

Turn the configuration's shortcut definitions into a clear, browsable reference. Success means a user can find a command or key sequence in seconds without reading TypeScript or generated Karabiner JSON.

## Brand Personality

Precise, calm, and technically literate. The interface follows Vercel's restrained editorial clarity and keeps the shortcut data primary.

## Anti-references

Avoid decorative keyboard dashboards, skeuomorphic keyboards, dense configuration editors, excessive cards, and interfaces that hide exact key sequences behind visual effects.

## Design Principles

1. Put the searchable shortcut index in the first viewport.
2. Show exact key sequences and plain-language outcomes together.
3. Preserve the layer structure so users can build muscle memory.
4. Support quick scanning without sacrificing complete coverage.
5. Keep interactions familiar and usable from the keyboard.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve visible focus, semantic controls, sufficient contrast, reduced-motion preferences, and descriptions that do not depend on color alone.
